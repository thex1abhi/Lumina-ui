# Lumina UI

Lumina UI is an AI-powered React component UI library that helps developers generate, preview, save, and publish reusable components in seconds. The platform combines a  library of ready-made components with an AI assistant that turns plain English prompts into usable React JSX.

## Project Highlights

- AI component generation from prompts
- Live code preview before export or save
- Reusable UI library with modern components
- FireBase authentication and user sessions
- Saved components per user
- Admin-only publishing flow to the shared library
- Razorpay-based credit purchasing for AI generation
- Component gallery and usage examples

## Tech Stack

- Frontend: React, Vite, Redux Toolkit, React Router, Tailwind CSS, Framer Motion
- UI preview: React Live
- Data visualization: Recharts
- Authentication: Firebase + custom backend auth flow
- Backend: Node.js, Express.js, MongoDB
- Payments: Razorpay
- AI integration: OpenRouter / AI component generation API
